# Vintage Barbershop

**Instructor-guided coursework | HTML, CSS, JavaScript**

This repository contains a barbershop website built as part of a web-development class. The project followed instructor-provided material and exercises, so it should be viewed as a learning assignment rather than an independently designed client project.

## What the project demonstrates

- Semantic HTML page structure and CSS styling
- Navigation and mobile-menu interactions
- JavaScript arrays and objects used to populate page content
- DOM selection, event handling, and interactive service information
- A calendar and appointment-booking interface for practice

## Running locally

Open `index.html` in a browser, or serve the repository with a local development server. No build step is required.

## Context

The design and core assignment were provided during class. This repository documents my practice implementing and understanding the material, not an original commercial barbershop website. Contact details shown in the demo are placeholders.
